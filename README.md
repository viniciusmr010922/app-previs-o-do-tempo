# 🌤️ Previsão do Tempo

Um aplicativo web simples e intuitivo para consultar o clima de qualquer cidade em tempo real, exibindo a temperatura, a condição meteorológica, a humidade e a velocidade do vento.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização moderna e layout responsivo.
- **JavaScript (ES6+)**: Lógica da aplicação, manipulação do DOM e requisições assíncronas com `fetch` e `async/await`.
- **WeatherAPI**: API REST para obtenção dos dados meteorológicos em tempo real.

## 📌 Funcionalidades

- 🔍 Busca de qualquer cidade do mundo pelo nome.
- 🌡️ Exibição da temperatura atual em graus Celsius.
- 💧 Consulta do nível de humidade do ar.
- 💨 Informação sobre a velocidade do vento.
- 🌦️ Ícones e descrições dinâmicas da condição do tempo em português.
